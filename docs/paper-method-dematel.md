# 논문용 DEMATEL 분석 방법

이 문서는 본 저장소의 `dematel/core.py`와 `dematel/threshold.py`에 구현된 분석을 논문의 연구방법(Method)과 재현성 부록에 기술하기 위한 문안이다. 본 구현은 불확실성 모형을 사용하지 않는 고전적(crisp) DEMATEL이다. DEMATEL은 복잡한 시스템의 요인 간 상호의존성과 인과적 방향을 행렬과 영향관계지도로 표현하는 구조모형화 기법으로, 최초의 방법론적 배경은 Gabus와 Fontela의 연구에 두고 있다(Gabus & Fontela, 1972; Si et al., 2018).

## 논문 본문에 바로 사용할 수 있는 방법 문안

### DEMATEL 분석

요인 간 상호의존적 영향관계를 분석하기 위해 Decision-Making Trial and Evaluation Laboratory(DEMATEL) 기법을 적용하였다. DEMATEL은 전문가가 평가한 직접 영향관계를 행렬로 통합한 뒤 직접·간접 영향의 총영향관계를 산출하고, 각 요인의 중심도와 순 영향방향을 이용하여 원인군과 결과군을 구분하는 방법이다(Gabus & Fontela, 1972; Tzeng et al., 2007; Si et al., 2018). 본 연구에서는 각 전문가가 요인 `i`가 요인 `j`에 미치는 직접 영향의 정도를 `[0, m]` 척도로 평가하였으며, 자기영향 `aᵢᵢ`는 0으로 설정하였다. 본 연구의 분석은 전문가별 행렬을 산술평균하여 하나의 집단 직접영향행렬을 구성하는 crisp DEMATEL 절차를 따랐다.

전문가 `h = 1, …, H`의 직접영향행렬을 `A⁽ʰ⁾ = [a⁽ʰ⁾ᵢⱼ]`라고 할 때, 집단 평균 직접영향행렬 `A = [aᵢⱼ]`는 다음과 같이 계산하였다.

```text
aᵢⱼ = (1 / H) × Σₕ₌₁ᴴ a⁽ʰ⁾ᵢⱼ
```

그 다음 행 합과 열 합 중 최댓값을 정규화 계수 `s`로 사용하여 정규화 직접영향행렬 `X`를 계산하였다.

```text
s = max { maxᵢ Σⱼ aᵢⱼ,  maxⱼ Σᵢ aᵢⱼ }
X = A / s
```

이 정규화는 모든 직접 영향값을 비교 가능한 범위로 변환하고, 후속 총영향행렬 계산이 수렴하도록 하는 전형적인 DEMATEL 절차이다(Si et al., 2018). 총영향행렬 `T`는 직접 영향과 모든 단계의 간접 영향을 합한 행렬로 다음과 같이 산출하였다.

```text
T = X + X² + X³ + ⋯ = X(I − X)⁻¹
```

여기서 `I`는 단위행렬이다. 수치 계산에서는 역행렬을 직접 계산하지 않고 `(I − X)T = X`에 해당하는 선형방정식을 풀었다. `(I − X)`가 특이하거나 조건수가 사전에 정한 수치 한계보다 큰 경우에는 결과를 산출하지 않도록 하였다.

각 요인 `i`의 총 영향력과 총 피영향력은 각각 총영향행렬의 행 합과 열 합으로 정의하였다.

```text
Rᵢ = Σⱼ tᵢⱼ       Cᵢ = Σⱼ tⱼᵢ
```

중심도(prominence)는 `Pᵢ = Rᵢ + Cᵢ`, 원인도(relation)는 `Dᵢ = Rᵢ − Cᵢ`로 계산하였다. 중심도가 클수록 해당 요인이 시스템의 다른 요인들과 주고받는 총 영향의 규모가 크다는 뜻이며, 원인도가 양수이면 순 영향 제공 요인(cause group), 음수이면 순 영향 수용 요인(effect group)으로 분류하였다. 원인도가 0에 가까운 경우에는 수치 허용오차 `10⁻¹²`를 기준으로 중립(neutral)으로 분류하였다. 따라서 이 분류는 인과효과의 통계적 검정이 아니라, 전문가 판단으로 구성된 영향 네트워크에서의 상대적 순 영향 방향을 의미한다.

### 추가 산출 지표와 영향관계 지도

본 시스템은 요인의 상대적 우선순위를 제시하기 위해 다음의 구현상 가중치를 추가로 계산하였다.

```text
w′ᵢ = √(Pᵢ² + Dᵢ²)
wᵢ = w′ᵢ / Σₖ w′ₖ
```

이 값은 중심도와 원인도의 2차원 좌표에서 원점까지의 유클리드 길이를 정규화한 값이며, 이 연구에서 사용하는 분석 결과 요약용 상대 가중치이다. 이는 DEMATEL의 원래 필수 산출물인 `R`, `C`, `R + C`, `R − C`와 구분하여 보고해야 한다.

영향관계지도(INRM)는 총영향행렬의 모든 비대각 원소를 표시할 때 발생하는 복잡성을 줄이기 위해 임계값 `θ` 이상인 관계만 표시하였다. 기본 설정에서 `θ`는 총영향행렬 `T`의 모든 원소(대각 원소 포함)의 산술평균이며, 관계 `i → j`는 `i ≠ j`이고 `tᵢⱼ ≥ θ`인 경우에만 지도에 표시하였다. 선택적으로 `θ = mean(T) + SD(T)` 또는 사용자가 지정한 값을 사용할 수 있다. 임계값은 인과성의 유의성 검정 기준이 아니라 시각화와 해석을 위한 관계 필터이다. 임계값 선택은 연구 결과의 재현성과 민감도에 영향을 주므로, 논문에서는 사용한 방법과 값을 함께 보고하고 가능하면 대안 임계값에 대한 민감도 분석을 제시해야 한다(Si et al., 2018).

INRM에서 가로축은 `Pᵢ = Rᵢ + Cᵢ`, 세로축은 `Dᵢ = Rᵢ − Cᵢ`로 설정하였다. 세로축의 0을 원인군과 결과군의 경계로, 가로축의 평균 중심도를 고중심도와 저중심도의 경계로 사용하여 네 사분면을 구성하였다. 이에 따라 제1사분면은 고중심도·원인군, 제2사분면은 저중심도·원인군, 제3사분면은 저중심도·결과군, 제4사분면은 고중심도·결과군을 나타낸다.

### 전문가 응답 안정성의 보조 진단

전문가 응답의 순차적 추가에 따른 평균행렬의 변화를 확인하기 위해 보조적인 합의도 Gap을 계산하였다. 업로드 순서에서 처음 `p − 1`명의 평균행렬을 `A⁽ᵖ⁻¹⁾`, 처음 `p`명의 평균행렬을 `A⁽ᵖ⁾`라고 하면, `p = 2, …, H`에 대한 Gap은 다음과 같다.

```text
Gapₚ(%) = [1 / |Mₚ|] × Σ₍ᵢ,ⱼ₎∈Mₚ
           |a⁽ᵖ⁾ᵢⱼ − a⁽ᵖ⁻¹⁾ᵢⱼ| / a⁽ᵖ⁾ᵢⱼ × 100
```

여기서 `Mₚ = {(i, j): i ≠ j, a⁽ᵖ⁾ᵢⱼ ≠ 0}`이다. 즉, 대각 원소와 p명 평균에서 0인 비대각 원소는 제외하고, 활성 비대각 셀에 대해 평균 상대변화를 계산하였다. 본 구현의 기본 참고 기준은 5%이며, Gap이 5% 미만이면 평균행렬의 변화가 작다고 표시한다. 그러나 이 지표는 전문가 모집의 충분성이나 측정 신뢰도를 검정하는 통계적 검정이 아니며, 업로드 순서에 의존하는 보조 진단이다. 따라서 논문에서는 이를 ‘합의도 검증 완료’라고 단정하기보다 ‘순차 평균 안정성 진단’으로 보고하고, 전문가 선정 근거·표본 수·응답자 간 신뢰도 분석과 구분하여 해석하였다.

## 분석 절차 요약

논문 또는 부록에서는 다음의 설정을 함께 보고해야 한다.

1. 전문가 수 `H`, 요인 수 `n`, 영향평가 척도와 척도 방향
2. 전문가별 직접영향행렬의 결합 방식(본 코드: 산술평균)
3. 정규화 계수의 정의(본 코드: 최대 행 합과 최대 열 합 중 최댓값)
4. 총영향행렬의 정의와 수치해법
5. `R`, `C`, `R + C`, `R − C`의 정의와 원인·결과 분류 기준
6. 추가 가중치 `wᵢ`를 사용한 경우 그 별도 정의
7. 임계값 방법과 실제 `θ`, 대각 원소 포함 여부(본 코드의 기본 평균은 포함)
8. 합의도 Gap을 보고한 경우 전문가 추가 순서, 제외 셀 규칙, 기준값
9. 입력 오류, 결측값, 대각 원소 보정 여부와 분석에서 제외된 파일

## 해석상의 주의점

- DEMATEL의 (R-C)는 전문가 평가로 구성된 네트워크에서의 순 영향 방향이며, 종단자료나 식별전략에 기반한 인과효과 추정치가 아니다.
- 전문가 수가 적거나 요인 간 영향평가의 주관성이 큰 경우 (T), (R+C), (R-C)가 평가척도와 전문가 구성에 민감할 수 있다.
- 평균행렬을 사용하면 전문가 간 이질성이 축약된다. 가능하면 개별 전문가 행렬의 분포, 민감도 분석, 또는 전문가 간 일치도 지표를 함께 제시한다.
- 임계값을 높이면 약한 관계가 제거되고 낮추면 지도에 많은 관계가 포함된다. 따라서 임계값을 바꿨을 때 핵심 원인군과 결과군이 유지되는지 확인하는 것이 바람직하다.
- 본 구현은 fuzzy DEMATEL, grey DEMATEL, DANP/ANP 결합 모형이 아니다. 해당 확장기법의 문헌과 결과를 혼동하지 않는다.
