# DEMATEL 분석 AI 시스템 — 사용자 설명서

전문가가 평가한 요인 간 영향 행렬(CSV)을 업로드하면 DEMATEL 분석을 수행해 지표 테이블, 인과 네트워크 지도(INRM), 결과 해석을 보여 주는 웹 앱입니다.

- 서비스 주소: **https://thugmba.thu.edu.tw**
- 지원 언어: English / 繁體中文 / 한국어

서비스 주소로 바로 사용하는 경우 [3. 사용 방법](#3-사용-방법)만 읽으면 됩니다. 1~2장은 앱을 직접 설치·운영하는 관리자용입니다.

## 1. 설치

### 1-1. 요구 사항

| 항목 | 조건 |
|---|---|
| 운영체제 | Ubuntu (학교 제공 가상 서버) 또는 Windows/WSL·macOS (로컬 PC) |
| Python | 3.11 이상 (`python3 --version`으로 확인) |
| 포트 | 3000번 (학교 서버는 `thugmba.thu.edu.tw` → 3000번으로 포워딩됨) |

### 1-2. 서버에 설치하고 실행

가상 서버에 SSH로 접속한 뒤 실행합니다.

```bash
# 3000번 포트를 다른 프로그램이 쓰고 있는지 확인
sudo ss -ltnp | grep :3000

# nginx가 3000번을 쓰고 있다면 중지 (이 앱에는 필요 없음)
sudo systemctl stop nginx
sudo systemctl disable nginx

# 내려받기 및 설치
cd ~
git clone https://github.com/thugmba/dematel.git
cd dematel
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

# 링크 미리보기 제목·설명 설정 (pip install 할 때마다 다시 실행)
.venv/bin/python scripts/patch_index_html.py

# (선택) AI 논문 문장 기능: 학교 LLM 정보를 .env 파일에 저장
cat > .env <<'EOF'
LLM_API_KEY=발급받은_API_키
LLM_MODEL=muse-spark-open
EOF
chmod 600 .env

# 백그라운드 실행 (SSH 접속을 끊어도 계속 실행됨)
nohup .venv/bin/streamlit run app.py > streamlit.log 2>&1 &
```

> `.env`가 없으면 AI 문장 기능만 꺼지고 나머지 기능은 그대로 동작합니다. `.env`는 GitHub에 올라가지 않으므로 서버마다 직접 만들어야 하며, 내용을 바꾼 뒤에는 앱을 다시 시작해야 합니다.

> 반드시 `dematel` 폴더 안에서 실행하세요. 포트 등 설정 파일(`.streamlit/config.toml`)을 실행 위치 기준으로 읽습니다.

### 1-3. 중지 · 업데이트

```bash
# 중지
pkill -f "streamlit run app.py"

# 새 버전으로 업데이트
pkill -f "streamlit run app.py"
cd ~/dematel && git pull
.venv/bin/pip install -r requirements.txt
.venv/bin/python scripts/patch_index_html.py
nohup .venv/bin/streamlit run app.py > streamlit.log 2>&1 &
```

로그 확인: `tail -f ~/dematel/streamlit.log`

### 1-4. 로컬 PC에 설치 (선택)

```bash
git clone https://github.com/thugmba/dematel.git
cd dematel
python3 -m venv .venv
source .venv/bin/activate          # Windows(명령 프롬프트): .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

브라우저에서 `http://localhost:3000`으로 접속합니다.

## 3. 사용 방법

### 3-1. 언어 선택

화면 오른쪽 위의 언어 메뉴에서 English / 繁體中文 / 한국어를 고릅니다. 언어를 바꿔도 업로드한 데이터와 설정은 유지됩니다. 처음 접속하면 브라우저 언어를 따르며, 주소 끝에 `?lang=ko`, `?lang=zh-TW`, `?lang=en`을 붙여 원하는 언어로 바로 열 수도 있습니다.

### 3-2. 입력 파일 준비

> **데이터가 없어도 됩니다.** 앱에 전문가 3명 × 요인 5개의 샘플 데이터가 내장되어 있어 **샘플 데이터 불러오기** 한 번으로 모든 기능을 체험할 수 있습니다. **샘플 파일 (ZIP)** 로 같은 파일을 내려받아 업로드 과정도 연습해 볼 수 있습니다.

**3가지만 지키면 됩니다.**

1. **전문가 1명 = CSV 파일 1개**
2. **첫 행과 첫 열**에 요인명을 같은 순서로 적습니다.
3. 나머지 칸에는 **행 요인이 열 요인에 주는 영향**을 0(없음) ~ 4(매우 큼) 점으로 적습니다. 대각선은 0입니다.

예: 아래에서 F2 행 · F3 열의 `4`는 "F2가 F3에 주는 영향이 4점"이라는 뜻입니다. **템플릿 다운로드** 버튼으로 예시 파일을 받아 고쳐 쓰면 편리합니다.

```csv
,F1,F2,F3,F4
F1,0,3,2,1
F2,1,0,4,2
F3,2,1,0,3
F4,0,2,1,0
```

| 점수 | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| 의미 | 영향 없음 | 낮음 | 보통 | 높음 | 매우 높음 |

- 모든 전문가 파일의 요인명과 순서가 같아야 합니다.
- 0–3, 0–5 등 다른 척도를 썼다면 사이드바의 **척도 최댓값**을 바꿉니다.
- Excel에서 작성했다면 **다른 이름으로 저장 → CSV UTF-8(쉼표로 분리)** 또는 **CSV(쉼표로 분리)** 로 저장합니다. 한글·중국어 요인명도 사용할 수 있습니다.

### 3-3. 파일 업로드

1. **Upload** 버튼을 누르거나 파일을 끌어다 놓습니다. 여러 파일을 한 번에 선택할 수 있습니다.
2. 처음 사용해 본다면 **샘플 데이터 불러오기**로 예시 결과를 먼저 확인해 보세요. 샘플로 분석 중일 때는 파란 안내 문구가 표시되며, 직접 만든 파일을 업로드하면 샘플이 교체됩니다.
3. 다른 데이터로 다시 분석하려면 **데이터 초기화**를 누릅니다.

### 3-4. 설정 (왼쪽 사이드바)

각 설정 옆의 **?** 아이콘에 마우스를 올리면 설명이 나오고, 사이드바 맨 아래 **설정 안내**를 펼치면 모든 설정을 한 번에 볼 수 있습니다.

| 설정 | 기본값 | 설명 |
|---|---|---|
| 척도 최댓값 | 4 | 평가 척도의 최고 점수. 0–3 척도이면 3, 0–5 척도이면 5. 이보다 큰 값은 오류로 처리 |
| 소수점 자릿수 | 3 | 표, INRM, 결과 해석의 표시 자릿수. 내려받는 CSV·Excel은 항상 전체 정밀도로 저장 |
| 합의도 기준 (%) | 5 | 합의도 Gap이 이 값보다 작으면 "합의 도달" (아래 설명 참고) |
| 전문가 이름 익명화 | 끔 | 켜면 결과·내보내기에서 파일명 대신 "전문가 1, 2, …"로 표시 |
| 임계값 방법 | T 평균 | 의미 있는 영향 관계를 고르는 기준 (아래 설명 참고) |

#### 합의도 Gap이란?

전문가를 업로드 순서대로 한 명씩 추가할 때, **마지막 전문가를 추가하면서 평균 행렬이 변한 정도(%)** 입니다.

- **Gap < 기준(5%)** → "합의 도달": 전문가를 더 추가해도 평균이 거의 변하지 않을 만큼 의견이 안정되었다는 뜻입니다.
- **Gap ≥ 기준** → "기준 초과 (참고)": 마지막 전문가 때문에 평균이 아직 크게 흔들린다는 뜻입니다. **분석 결과가 틀렸다는 뜻은 아니며** 분석은 그대로 진행됩니다. 연구 보고 시에는 전문가를 더 모집하거나, 응답이 크게 다른 전문가를 검토하거나, 이 한계를 함께 밝히는 것을 고려하세요.
- 5%는 DEMATEL 연구의 관례적인 값입니다. 전문가가 1명이면 계산하지 않습니다.
- 단계별(2명 → 3명 → …) Gap은 **중간 행렬** 탭의 **합의도 Gap** 표에서 볼 수 있습니다.

#### 임계값 θ란?

총영향행렬 T의 모든 관계를 그리면 지도가 복잡해지므로, **tᵢⱼ ≥ θ인 관계만 의미 있는 관계로 봅니다.** 이 관계들만 INRM 화살표로 그려지고, T에서 노란색으로 강조되며, 결과 해석에 포함됩니다.

| 방법 | 언제 쓰나 |
|---|---|
| T 평균 (기본) | 가장 널리 쓰이는 기준. 특별한 이유가 없으면 그대로 사용 |
| 평균 + 표준편차 | 화살표가 너무 많아 지도가 복잡할 때 핵심 관계만 보고 싶을 때 |
| 사용자 지정 | 슬라이더로 θ를 직접 조정. 범위는 T의 대각선 제외 최솟값~최댓값이며, 높일수록 강한 관계만 남음 |

사이드바의 "관계 20개 중 10개 표시"는 서로 다른 요인 간 관계 n(n−1)개 중 θ 이상인 관계의 수입니다.

### 3-5. 오류·경고 메시지

업로드한 파일에 문제가 있으면 파일명과 위치(행·열)가 함께 표시됩니다.

| 종류 | 예시 | 처리 |
|---|---|---|
| 오류 (빨간색) | 정사각 행렬이 아님, 빈 칸, 숫자가 아닌 값, 척도 범위 초과, 요인명 불일치, 전문가 간 요인 불일치 | 분석 중단 → 파일 수정 후 다시 업로드 |
| 경고 (노란색) | 대각선 값이 0이 아님, 소수 값 | 자동 보정(대각선 → 0) 또는 그대로 사용하고 분석 계속 |

### 3-6. 결과 보기

화면 위쪽에 요약 지표가 표시되고, 아래 5개 탭에서 결과를 확인합니다.

**요약 지표**: 전문가 수, 요인 수, 정규화 계수 s, 합의도 Gap(전문가 2명 이상일 때)

| 탭 | 내용 |
|---|---|
| **지표 테이블** | 요인별 R(주는 영향), C(받는 영향), R+C(중심도: 중요도), R−C(원인도: 양수면 원인, 음수면 결과), 가중치, 순위, 구분. 열 머리글을 누르면 정렬됩니다. |
| **INRM** | 가로축 R+C, 세로축 R−C의 인과 네트워크 지도. 빨간 점은 원인 요인, 파란 점은 결과 요인이며, 화살표는 임계값 이상의 영향 관계(굵을수록 강함)입니다. 점이나 화살표 중간에 마우스를 올리면 값이 보입니다. 아래 표에 사분면별 요인과 해석이 정리됩니다. |
| **결과 해석** | **요약**: 중심도 상위 요인, 원인군·결과군, 가장 강한 원인·결과 요인, 사분면별 분류, 주요 영향 관계를 글머리표로 요약합니다. **연구 결과 문단 (AI)**: 아래 3-7 참고. 지표 테이블·INRM·중간 행렬 탭 아래에도 각 탭용 AI 문장 영역이 있습니다. |
| **중간 행렬** | 평균 직접영향행렬 A, 정규화 행렬 X, 총영향행렬 T(임계값 이상 셀 노란색 강조), 전문가 수별 합의도 Gap |
| **내보내기** | 결과 파일 다운로드 (3-8 참고) |

**사분면 해석**

| 사분면 | 위치 | 의미 |
|---|---|---|
| Ⅰ | 오른쪽 위 (중심도 높음, 원인) | 핵심 원인 요인 — 우선 관리 대상 |
| Ⅱ | 왼쪽 위 (중심도 낮음, 원인) | 독립적 원인 요인 — 다른 요인에 일부 영향 |
| Ⅲ | 왼쪽 아래 (중심도 낮음, 결과) | 독립적 결과 요인 — 상대적 중요도 낮음 |
| Ⅳ | 오른쪽 아래 (중심도 높음, 결과) | 핵심 결과 요인 — 원인 요인 개선으로 간접 관리 |

**임계값 조정** (사이드바)

| 방법 | 설명 |
|---|---|
| T 평균 | 가장 널리 쓰이는 기본값 |
| 평균 + 표준편차 | 관계가 너무 많아 지도가 복잡할 때 핵심 관계만 표시 |
| 사용자 지정 | 슬라이더로 직접 조정하면 지도·해석·강조 셀이 즉시 바뀜 (3-4 참고) |

### 3-7. 논문용 문장 만들기 (AI)

학교 LLM으로 각 탭의 결과를 논문 문장으로 만듭니다. **베타 버전 기간 중에는 AI 기능을 무료로 사용할 수 있습니다.** **분석과 모든 수치는 프로그램(Python)이 계산하고, AI는 그 결과를 문장으로 옮기기만 합니다.**

| 탭 | 만들어지는 문장 |
|---|---|
| 지표 테이블 | 표 제목, 표 주석(기호 정의), 표 설명 문단 |
| INRM | 그림 제목, 그림 설명 문단 |
| 결과 해석 | 연구 결과(Results) 문단 |
| 중간 행렬 | 분석 절차(연구 방법) 문단 |

1. 왼쪽 사이드바 **AI 논문 문장**에서 **작성 언어**를 확인합니다. 기본값은 화면 언어이며 다른 언어로 바꿀 수 있습니다.
2. (선택) **연구 맥락**에 연구 주제를 한 줄로 적습니다. 예: "대만 중소기업의 디지털 전환 핵심 요인"
3. 원하는 탭 아래쪽의 **문장 생성**을 누릅니다. 보통 10초 안팎 걸립니다.
4. 결과 아래 **✓ 수치 검증 통과** 표시를 확인한 뒤, **복사용 텍스트**에서 복사하거나 **초안 다운로드 (.txt)** 로 저장합니다.

- **숫자를 AI가 쓰지 않습니다.** AI는 숫자 자리에 표시만 남기고, 프로그램이 계산값을 채워 넣습니다. AI가 숫자를 직접 쓰면 자동으로 다시 요청하고, 세 번 모두 실패하면 문장을 보여 주지 않고 오류를 표시합니다.
- 그래도 **문장 표현과 해석이 맞는지는 반드시 검토**하세요. 값은 정확하지만 문장 속 위치나 조사("Training가")가 어색할 수 있습니다.
- 표·그림 번호는 "표 X", "그림 X"(영어: Table X, Figure X)로 나오니 논문에 맞게 바꾸세요.
- **다시 생성**을 누르면 다른 표현의 초안이 나옵니다. 임계값·소수점 자릿수·언어·연구 맥락을 바꾸면 그에 맞는 새 초안을 만들 수 있습니다.
- "설정되지 않았습니다"라고 나오면 서버 관리자에게 문의하세요 (1-2의 `.env` 설정).

### 3-8. 결과 내보내기

**내보내기** 탭에서 다운로드합니다.

| 파일 | 내용 |
|---|---|
| 지표 테이블 (CSV) | 요인별 R, C, R+C, R−C, 가중치, 순위, 구분 |
| 행렬 A / X / T (CSV) | 각 행렬 |
| 전체 결과 (Excel) | 전문가별 입력, A, X, T, 지표, 설정을 시트별로 저장 |
| INRM 그림 | INRM 탭에서 형식(png/svg)을 고른 뒤, 지도 오른쪽 위 도구 막대의 **카메라 아이콘** 클릭 |

CSV와 Excel의 머리글은 선택한 언어로 저장됩니다. CSV는 Excel에서 바로 열어도 한글·중국어가 깨지지 않습니다.

### 3-9. 데이터 보안

업로드한 파일은 분석하는 동안 서버 메모리에서만 처리되며 저장되지 않습니다. 브라우저 탭을 닫으면 데이터가 삭제되므로, 필요한 결과는 닫기 전에 내려받으세요.

각 탭의 AI 영역에서 **문장 생성** 버튼을 누른 경우에만 요인명과 분석 결과 수치가 학교 LLM 서버로 전송됩니다. 업로드한 파일 자체는 전송되지 않습니다.
